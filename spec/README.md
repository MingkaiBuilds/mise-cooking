# Mise public contracts

This directory is the staging area for interoperable, versioned Mise contracts.

`recipe-record.v1.schema.json` is a prospective record contract, not yet a promise that the current pilot API implements every field. It exists now so provenance, confidence, safety, record status, creator attribution, and licensing are designed before the dataset grows.

The contract becomes a supported public API schema only after:

- production records implement it;
- fixtures and compatibility tests exist;
- rights and correction workflows are operational;
- an OpenAPI description and deprecation policy are published; and
- the first stable version is explicitly announced.
